# Frontend

Next.js 15 App Router со строгим TypeScript. Запуск через Docker Compose описан в [корневом README](../README.md). Серверный адрес Symfony задаётся `INTERNAL_API_URL`.

UI использует нейтральную тему Astryx в светлом режиме с локальными цветовыми токенами в `src/app/globals.css`: снежный фон, светло-синие поверхности, тёмно-синий текст и красные новогодние акценты. Общий декоративный снег виден на страницах сайта, гирлянда — в шапке кабинета и админки; обе анимации отключаются при `prefers-reduced-motion: reduce`. Стили отдельных экранов находятся в SCSS Modules; при добавлении экранов используйте те же токены и проверяйте контраст, клавиатурный фокус и уменьшение анимации.
