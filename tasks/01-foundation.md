# 01. Основа проекта

**Зависит от:** ничего.

## Сделать

- Создать приложения Symfony 7/PHP 8.3+ и Next.js 15/App Router/strict TypeScript с указанными в ТЗ библиотеками по мере фактического использования.
- Поднять PostgreSQL 16, backend и frontend через Docker Compose; добавить пример переменных окружения, миграции, локальный том `/uploads`.
- Зафиксировать UTC для хранения времени и `APP_TIMEZONE=Europe/Moscow` для открытия дней; описать запуск и миграции.
- Согласовать формат REST JSON `/api/v1`: UUID в публичных маршрутах, ISO 8601, ошибки `{code, message}`, пагинация списков, правила выбора текущего календаря.
- Описать контракт аутентификации NextAuth Credentials ↔ Symfony Security: выдача/передача учётных данных API, серверная проверка роли и защита мутаций.

## Готово, когда

- Чистая установка поднимается по инструкции; frontend достигает backend, backend — БД, миграции запускаются.
- Секреты не хранятся в репозитории; `/uploads` сохраняется между перезапусками контейнера.
