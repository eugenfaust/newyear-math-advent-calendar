# 14. Завершение дня и награда: frontend

**Зависит от:** 12, 13.

## Сделать

- Добавить кнопку «Задание выполнено» для доступного дня; отправлять mutation через TanStack Query, блокировать повторное нажатие на время запроса.
- Для проверяемых типов показывать ввод числа/текста или выбор варианта и сообщение о неверном ответе с возможностью повторить попытку.
- После ответа показать модальное окно с выданной игрушкой и переходом к ёлке; обновить кэши дня и календаря.
- Обрабатывать повторный ответ тем же результатом и ошибки по стабильному `code`.

## Готово, когда

- Завершение отражается в сетке после обновления страницы; пользователь видит именно выданную backend игрушку.
- Повторное нажатие или повторный запрос не показывают новую награду.
