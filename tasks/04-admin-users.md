# 04. Управление пользователями

**Зависит от:** 02, 03.

## Сделать

- Реализовать admin API для списка, просмотра, создания и редактирования пользователей: имя, login, email, роль, активность, установка/смена пароля.
- Добавить `/admin/users` и `/admin/users/[uuid]` с формами, валидацией, поиском и понятными ошибками уникальности.
- «Удаление» для MVP реализовать как деактивацию, чтобы сохранить историю календарей и наград.

## Готово, когда

- Администратор создаёт пользователя, меняет данные и отключает доступ; login остаётся уникальным.
- Обычный пользователь не может управлять пользователями через UI или прямой API-запрос.
