# 11. Доступность дней и пользовательский API

**Зависит от:** 10.

## Сделать

- Реализовать `GET /api/v1/calendar` со статусами 31 дня и счётчиками, `GET /api/v1/calendar/days/{day}` с данными задания.
- Вычислять дату открытия в `APP_TIMEZONE` на backend, не по времени браузера. До 1 декабря дни закрыты; пропущенные дни доступны впоследствии, в том числе после 31 декабря.
- При первом успешном открытии записывать `openedAt` один раз; закрытый день отдаёт 403 с `ADVENT_DAY_LOCKED` без текста задания и ответа.
- Гарантировать, что запросы работают только с календарём текущего пользователя; явно определить выбор текущего года для endpoint без параметра.

## Готово, когда

- Границы 30 ноября / 1 декабря / 31 декабря / 1 января проверены в бизнес-часовом поясе.
- Прямой запрос будущего дня и запрос к чужому календарю не раскрывают задание.
