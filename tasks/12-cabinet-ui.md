# 12. Кабинет и страница дня

**Зависит от:** 06 (рендерер), 11.

## Сделать

- Реализовать `/cabinet`: имя, календарь, прогресс, число доступных дней, сетка 1–31, переход к ёлке.
- Реализовать `/cabinet/day/[day]`: дата, заголовок, Markdown/math, изображение, состояния locked/available/expired/completed.
- Показывать дату открытия будущего дня без загрузки содержимого; истёкший незавершённый день обозначать отдельно и не загружать его задание.
- Предусмотреть состояния без назначенного календаря, загрузку и ошибки по коду API.

## Готово, когда

- Сетка соответствует состояниям backend; нельзя получить будущий текст через прямой переход или кэш frontend.
- Страницы читаемы на телефоне и компьютере.
