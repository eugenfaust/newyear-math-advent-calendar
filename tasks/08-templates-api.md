# 08. Шаблоны: домен и API

**Зависит от:** 05.

## Сделать

- Создать `AdventTemplate` и `AdventTemplateTask`, миграции и ограничения `1 ≤ day ≤ 31`, `UNIQUE(template_id, day)`.
- Реализовать admin CRUD шаблонов, выбор/замену/очистку задания для дня, чтение всех 31 позиций и проверку полноты.
- Реализовать копирование шаблона вместе со всеми назначениями дней в одной транзакции.
- Запретить назначение неполного шаблона; определить, можно ли добавлять деактивированное задание (для нового назначения — нет).

## Готово, когда

- Одно задание может быть в нескольких шаблонах; один день шаблона содержит не более одного задания.
- Копия содержит те же 31 назначения и может редактироваться независимо; проверка полноты возвращает `TEMPLATE_INCOMPLETE` для неполного шаблона.
