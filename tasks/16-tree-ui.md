# 16. Ёлка: SVG и взаимодействие

**Зависит от:** 14, 15.

## Сделать

- Реализовать `/cabinet/tree`: SVG-ёлка со стабильным `viewBox`, ровно 31 слот в статической frontend-конфигурации, отображение размещённых игрушек и инвентаря.
- Основной сценарий: выбрать игрушку → увидеть свободные слоты → нажать слот → отправить запрос → обновить данные. Уже размещённую игрушку можно выбрать и переместить.
- Добавить доступные состояния выбора, занятости и ошибки конфликта; кнопки/слоты должны работать с клавиатурой и касанием.
- Адаптировать композицию для mobile/tablet/desktop; координаты и дизайн дерева не хранить в БД.
- На dashboard показать число игрушек без места и CTA «Украсить ёлку» по данным API задачи 15.

## Готово, когда

- На телефоне пользователь размещает и перемещает игрушку без drag-and-drop.
- Все 31 позиции достижимы, занятые слоты нельзя выбрать, состояние совпадает с API после перезагрузки.
