# 06. Интерфейс библиотеки заданий

**Зависит от:** 03, 05.

## Сделать

- Добавить `/admin/tasks`, `/admin/tasks/create`, `/admin/tasks/[uuid]`: список, поиск, фильтры, форма, загрузка, деактивация.
- Сделать общий компонент безопасного отображения Markdown с `remark-math`, `rehype-katex` и KaTeX; применять его и в admin preview, и на странице пользователя.
- Показывать предпросмотр загруженного изображения, текста и формул; валидировать форму через Zod/React Hook Form.
- Дать выбрать тип ответа `NONE`, `NUMBER`, `TEXT` или `MULTIPLE_CHOICE`, задать правильный ответ и варианты выбора для последнего типа.

## Готово, когда

- Администратор видит текст, формулы и изображение в том же виде, в каком их увидит пользователь.
- Ввод Markdown не приводит к исполнению произвольного HTML/скриптов.
