# 15. Ёлка: API размещения

**Зависит от:** 13.

## Сделать

- Добавить nullable `treeSlot` (1–31), `placedAt` и `updatedAt` в `UserOrnament`; миграция с CHECK диапазона и частичным `UNIQUE(calendar_id, tree_slot) WHERE tree_slot IS NOT NULL`.
- Реализовать `GET /api/v1/tree` для текущего календаря: выданные игрушки, слот, `completedDays`, итоговое состояние.
- Реализовать `POST /api/v1/tree/ornaments/{uuid}/place` для размещения и перемещения; проверить владельца, календарь, диапазон и свободное место.
- При конкурентном занятии слота опираться на ограничение БД и возвращать `TREE_SLOT_OCCUPIED`; повторное размещение в тот же слот делать безопасным.

## Готово, когда

- Игрушка сохраняет слот после перезагрузки; нельзя повесить чужую игрушку или занять слот дважды.
- После 31 выполненного дня API сообщает состояние завершения.
