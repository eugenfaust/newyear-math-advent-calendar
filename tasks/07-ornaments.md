# 07. Библиотека игрушек

**Зависит от:** 03, 05 (хранилище файлов).

## Сделать

- Создать `Ornament`: UUID, name, imagePath, isActive, даты; nullable rarity/weight оставить только если это не усложняет MVP. Добавить миграцию и admin CRUD.
- Реализовать `/admin/ornaments`, `/admin/ornaments/create`, `/admin/ornaments/[uuid]`: загрузка SVG/PNG/WebP, предпросмотр, изменение и деактивация.
- Проверять тип и содержимое файлов; SVG отдавать как изображение, не вставлять непроверенный markup в DOM.
- Сохранять ранее выданные игрушки доступными для отображения после деактивации справочника.

## Готово, когда

- Администратор создаёт набор игрушек и управляет активностью; файлы отображаются после рестарта.
- Неактивная игрушка не участвует в новых выдачах.
