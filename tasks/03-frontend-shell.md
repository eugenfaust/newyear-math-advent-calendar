# 03. Оболочка frontend

**Зависит от:** 01, 02.

## Сделать

- Подключить Astryx Design System (`@astryxdesign/core`, `@stylexjs/stylex`, `@astryxdesign/theme-neutral`) по [официальному руководству](https://astryx.atmeta.com/docs/getting-started): базовые CSS, тему и провайдер `Theme` в корневом layout. Использовать компоненты Astryx для оболочки и форм.
- Подключить TanStack Query, React Hook Form, Zod, SCSS Modules и Tabler Icons.
- Создать `/login`, базовые layout `/cabinet` и `/admin`, состояния загрузки/ошибки и выход из системы.
- Создать типизированный API-клиент: авторизация по контракту задачи 01, разбор `code`, единая обработка 401/403.
- Защитить маршруты с учётом сессии и роли; backend остаётся окончательной проверкой доступа.

## Готово, когда

- Пользователь попадает в кабинет, администратор — в админку; недоступные маршруты не раскрывают данные.
- Обновление страницы не теряет корректную сессию; выход прекращает доступ.
